# 版本记录

## v0.1.0-mvp

版本定位：

- MVP 主流程已跑通。
- 当前可用于演示和后续迭代。
- 当前仍为 mock AI。
- 当前执行引擎为 Pytest + Requests。

已支持能力：

- 支持项目管理。
- 支持环境配置。
- 支持 Swagger/OpenAPI 或 curl 导入。
- 支持接口资产管理。
- 支持 mock AI 用例生成。
- 支持测试用例管理。
- 支持 Pytest + Requests 执行。
- 支持执行结果和报告查看。

核心路径：

```text
AI 模块：backend/app/ai
Pytest 模板：backend/app/generator/templates/pytest_project
生成工程：storage/generated/project_{project_id}/execution_{task_id}/
测试报告：storage/reports/execution_{task_id}/report.html
执行日志：storage/logs/execution_{task_id}/pytest.log
上传文件：storage/uploads
```

核心数据库表：

```text
project
environment
api_document
api_endpoint
test_case
execution_task
execution_result
test_report
ai_analysis_record
```

当前限制：

- 未接真实 AI 大模型。
- 未实现在线接口文档 URL 导入与 AI 辅助解析。
- 未支持 Knife4j / Swagger UI `doc.html` 页面地址自动解析。
- 未实现复杂接口依赖编排。
- 未实现复杂 token 自动刷新。
- 未实现权限系统、CI/CD、多用户协作和生产级部署方案。

后续路线：

- 第 9 阶段：在线接口文档 URL 导入与 AI 辅助解析。
- 第 10 阶段：真实 AI 大模型接入。
- 第 11 阶段：接口依赖关系与链路用例。
- 第 12 阶段：鉴权、token、cookie 增强。
- 第 13 阶段：报告和失败分析增强。
- 第 14 阶段：CI/CD、定时任务与权限系统。
