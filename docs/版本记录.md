# 版本记录

## v0.1.0-mvp

MVP 主流程已跑通，当前可用于演示和后续迭代。

支持能力：

- 项目管理
- 环境配置
- Swagger/OpenAPI 或 curl 导入
- 接口资产管理
- mock AI 用例生成
- 测试用例管理
- Pytest + Requests 执行
- 执行结果和报告查看

核心路径：

```text
AI 模块：backend/app/ai
Pytest 模板：backend/app/generator/templates/pytest_project
生成工程：storage/generated/project_{project_id}/execution_{task_id}/
测试报告：storage/reports/execution_{task_id}/report.html
执行日志：storage/logs/execution_{task_id}/pytest.log
上传文件：storage/uploads
```

## 第 9 阶段更新

第 9 阶段在 `v0.1.0-mvp` 基线上增强接口导入能力：

- 支持在线 OpenAPI/Swagger JSON URL。
- 支持 Knife4j / Swagger UI 页面地址自动发现真实 JSON 文档。
- 支持 `/v3/api-docs`、`/v2/api-docs`、`/swagger-resources`、`/api-docs`、`/openapi.json`、`/swagger.json` 候选地址。
- 支持单接口文档页面 URL 的 hash hint 筛选。
- 支持接口路径、请求方法、名称、分组、关键词筛选。
- 支持 Swagger/OpenAPI JSON 内容。
- 保留 curl 文本导入。
- 支持仅预览、保存选中、保存全部。
- 保存前允许用户编辑确认。
- 未找到已有接口资产时只创建待完善接口草稿。
- 支持基础 `$ref` 展开。
- 支持参数 JSON、Body JSON、响应 JSON 的“展开示例 / 展开 Schema”切换。
- 支持编辑预览 JSON 并保存到接口资产。
- 支持执行报告页多选测试用例执行。
- 支持展开单条执行结果，查看并复制请求参数 JSON、响应体 JSON 和 curl 命令。

## 第 10 阶段更新

第 10 阶段在 `v0.1.0-stage9` 基线上增强鉴权配置与业务断言能力：

- 环境配置页支持鉴权类型、Token、Cookie、Header JSON、`auth_config_json`、timeout 和 retry。
- 执行引擎自动合并环境公共 headers、环境鉴权 headers 和测试用例请求 headers。
- 请求头合并优先级为：环境公共 headers < 环境鉴权 headers < 测试用例请求 headers。
- 支持 `business_code`、`business_success`、`json_path_not_empty` 业务断言。
- 响应 JSON 中存在 `code` 或 `success` 且测试用例未显式断言时，自动补充默认业务断言。
- 避免 HTTP 200 但业务失败仍被判定为通过。
- 执行结果保存脱敏后的请求数据、响应体、curl 命令和断言结果。
- 非 JSON 响应会保存原始文本、Content-Type 和 JSON 解析错误提示。
- 执行报告页展示断言结果，并继续支持请求参数、响应体、curl 的展开和复制。
- 当前仍不支持自动 token 刷新、自动登录、验证码、SSO 或浏览器自动化登录。
- 当前仍为 mock AI，未接入真实大模型。

后续路线：

- 第 11 阶段：真实 AI 大模型接入
- 第 12 阶段：接口依赖关系与链路用例
- 第 13 阶段：报告和失败分析增强
- 第 14 阶段：CI/CD、定时任务与权限系统
