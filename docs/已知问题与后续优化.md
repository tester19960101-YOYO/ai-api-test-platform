# 已知问题与后续优化

## 当前已知问题

- 前端未配置 lint 命令，因此当前无法执行 `npm run lint`。
- 前端生产构建存在主 chunk 超过 500 kB 的提示，当前不影响 MVP 演示。
- 当前 PowerShell 进程可能无法直接识别 `mysql` 命令，需要使用 MySQL CLI 绝对路径或重启终端继承 PATH。
- 当前演示数据主要用于本地验证，未提供生产级种子数据管理。

## 当前限制

- 当前仍为 mock AI。
- 未接真实大模型。
- 未支持输入 Knife4j / Swagger UI 的 `doc.html` 页面地址并自动解析。
- 未实现在线接口文档 URL 导入与 AI 辅助解析。
- 未实现复杂接口依赖编排。
- 未实现复杂 token 自动刷新。
- 未实现 Word/PDF 解析。
- 未实现 CI/CD。
- 未实现权限系统。
- 未实现多用户协作。
- 未实现 WebSocket 实时日志。
- 未实现生产级部署方案。
- 未实现 SSO、验证码或扫码登录。
- 未实现并发压测。
- 未实现复杂 Allure 报告。
- 未实现 httpx 异步执行。

## MVP 后增强方向

第 9 阶段：在线接口文档 URL 导入与 AI 辅助解析

- 支持输入 Knife4j / Swagger UI 的 `doc.html` 页面地址。
- 自动识别真实 OpenAPI JSON 地址。
- 支持在线接口文档抓取和解析。
- 使用 AI 辅助修正常见接口文档结构问题。
- 将解析结果保存到 `api_document` 和 `api_endpoint`。

第 10 阶段：真实 AI 大模型接入

- 接入真实大模型服务。
- 保持 AI 输出为结构化 JSON。
- 增强用例生成质量。
- 增强断言生成能力。
- 保持 AI 不直接生成自由 Python 代码。

第 11 阶段：接口依赖关系与链路用例

- 识别接口之间的数据依赖。
- 支持前置接口和后置接口。
- 支持变量提取和变量传递。
- 生成链路测试用例。

第 12 阶段：鉴权、token、cookie 增强

- 增强环境级鉴权配置。
- 支持 token 获取和刷新。
- 支持 cookie 管理。
- 支持常见鉴权方式模板。

第 13 阶段：报告和失败分析增强

- 增强执行报告展示。
- 增强失败原因聚合。
- 增加 AI 失败分析。
- 增加报告总结。

第 14 阶段：CI/CD、定时任务与权限系统

- 支持定时执行任务。
- 支持 CI/CD 集成。
- 增加用户、角色和权限模型。
- 支持团队协作和审计记录。

## 当前处理原则

- 当前 `v0.1.0-mvp` 优先保持稳定、可复现、可演示。
- MVP 后增强功能不提前进入当前基线。
- 新能力开发前需要先更新对应设计文档和阶段范围。
- 真实 AI 接入后仍必须遵守结构化 JSON 输出边界。
