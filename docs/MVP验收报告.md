# MVP 验收报告

## 验收结论

AI API Test Platform / AI 接口自动化测试平台的 MVP 主流程已跑通，当前基线版本为 `v0.1.0-mvp`，并已完成第 9 阶段“多形态接口输入导入与 AI 辅助解析”增强。

当前版本达到可演示状态，也可以继续作为后续迭代基础。

## 已跑通主流程

1. 创建项目。
2. 配置环境。
3. 导入接口文档。
4. 预览、筛选、编辑确认并保存接口资产。
5. 查看接口列表和接口详情。
6. 基于接口资产生成 mock AI 测试用例。
7. 管理测试用例。
8. 调用 Pytest + Requests 执行测试。
9. 保存执行任务、执行结果和测试报告。
10. 前端查看执行结果和报告路径。

## 第 9 阶段验收内容

已支持：

- 在线 OpenAPI/Swagger JSON URL。
- Knife4j / Swagger UI `doc.html` 页面地址自动发现真实 JSON 文档。
- 候选地址 `/v3/api-docs`、`/v2/api-docs`、`/swagger-resources`、`/api-docs`、`/openapi.json`、`/swagger.json`。
- 单接口文档页面 URL hash hint 提取和筛选。
- 接口路径、请求方法、接口名称、分组、关键词筛选。
- Swagger/OpenAPI JSON 内容粘贴。
- curl 文本导入。
- 仅预览不保存。
- 保存选中接口。
- 保存全部接口。
- 保存前编辑确认。
- 无结构化文档时不让 AI 凭空生成完整接口参数。

## 当前限制

- AI 仍为 mock，未接真实大模型。
- AI 辅助解析不会从 HTML 页面凭空生成完整接口结构。
- 未实现复杂接口依赖编排。
- 未实现复杂 token 自动刷新。
- 未实现 Word/PDF 解析。
- 未实现权限系统、SSO、多用户协作。
- 未实现 CI/CD 和定时任务。
- 未实现 WebSocket 实时日志。
- 未实现生产级部署方案。

## 后续建议迭代方向

- 第 10 阶段：真实 AI 大模型接入。
- 第 11 阶段：接口依赖关系与链路用例。
- 第 12 阶段：鉴权、token、cookie 增强。
- 第 13 阶段：报告和失败分析增强。
- 第 14 阶段：CI/CD、定时任务与权限系统。
