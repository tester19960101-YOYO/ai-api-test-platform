# MVP 验收报告

## 验收结论

AI API Test Platform / AI 接口自动化测试平台的 MVP 主流程已跑通，当前基线版本为 `v0.1.0-mvp`，并已完成第 9 阶段“多形态接口输入导入与 AI 辅助解析”、第 10 阶段“鉴权配置与业务断言增强”和第 10.1 阶段“断言系统 2.0 融合引擎 / DSL 可视化系统”。

当前版本达到可演示状态，也可以继续作为后续迭代基础。

## 已跑通主流程

1. 创建项目。
2. 配置环境。
3. 导入接口文档。
4. 预览、筛选、编辑确认并保存接口资产。
5. 查看接口列表和接口详情。
6. 基于接口资产生成 mock AI 测试用例。
7. 管理测试用例。
8. 调用 Pytest + Requests 执行测试。
9. 保存执行任务、执行结果和测试报告。
10. 前端查看执行结果、请求参数、响应体、curl、断言系统 2.0 结果和报告路径。
11. 在测试用例中通过 DSL 可视化编辑器查看 AI 断言建议、Swagger 断言、用户断言和最终融合断言预览。

## 第 9 阶段验收内容

已支持：

- 在线 OpenAPI/Swagger JSON URL。
- Knife4j / Swagger UI `doc.html` 页面地址自动发现真实 JSON 文档。
- 候选地址 `/v3/api-docs`、`/v2/api-docs`、`/swagger-resources`、`/api-docs`、`/openapi.json`、`/swagger.json`。
- 单接口文档页面 URL hash hint 提取和筛选。
- 接口路径、请求方法、接口名称、分组、关键词筛选。
- Swagger/OpenAPI JSON 内容粘贴。
- curl 文本导入。
- 仅预览不保存。
- 保存选中接口。
- 保存全部接口。
- 保存前编辑确认。
- 无结构化文档时不让 AI 凭空生成完整接口参数。

## 第 10.1 阶段验收内容

已支持：

- AI 断言建议、Swagger/OpenAPI 基础断言、用户断言三层融合。
- 用户断言优先级最高，Swagger/OpenAPI 断言作为基础层，AI 断言仅作为建议层。
- `business_code` 不再写死为 1，支持 `success_codes` 和 `success_expression`。
- `$.data` 相关 JSONPath 仅在业务成功后执行。
- 执行结果保留最终融合断言和断言来源。
- 前端展示 AI 断言建议、Swagger 断言、用户断言和最终融合断言预览。
- DSL 可视化断言编辑器支持新增、删除、编辑、复制和一键插入。
- AI / Swagger / 用户断言统一展示为 DSL。

## 当前限制

- AI 仍为 mock，未接真实大模型。
- AI 辅助解析不会从 HTML 页面凭空生成完整接口结构。
- AI 断言建议不决定测试通过或失败。
- Swagger/OpenAPI 断言当前为基础层，复杂 schema 深度校验后续继续增强。
- DSL 当前不支持 AND/OR 复合表达式。
- 未实现复杂接口依赖编排。
- 未实现复杂 token 自动刷新。
- 未实现自动登录、验证码、SSO 或浏览器自动化登录。
- 未实现 Word/PDF 解析。
- 未实现权限系统、SSO、多用户协作。
- 未实现 CI/CD 和定时任务。
- 未实现 WebSocket 实时日志。
- 未实现生产级部署方案。

## 后续建议迭代方向

- 第 11 阶段：真实 AI 大模型接入。
- 第 12 阶段：接口依赖关系与链路用例。
- 第 13 阶段：报告和失败分析增强。
- 第 14 阶段：CI/CD、定时任务与权限系统。
