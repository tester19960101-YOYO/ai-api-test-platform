# 前端页面设计

## 当前阶段说明

当前项目已完成第六阶段：Vue3 前端 MVP 页面，第七阶段已完成 MVP 联调验收，第八阶段已固化 MVP 基线为 `v0.1.0-mvp`。

前端已初始化 Vue3 + TypeScript + Vite 工程，并接入 Element Plus、Vue Router、Pinia 和 Axios。当前目标是跑通测试人员的 MVP 业务闭环，不追求复杂 UI、高级交互或生产级可视化编排。

## 技术栈

- Vue3
- TypeScript
- Vite
- Element Plus
- Vue Router
- Pinia
- Axios

## API 调用规范

- 统一请求封装位置：`frontend/src/api/http.ts`
- API 方法位置：`frontend/src/api/index.ts`
- 默认 baseURL：`/api/v1`
- Vite dev server 将 `/api/v1` 代理到 `http://127.0.0.1:8000`
- 请求和响应错误通过 Element Plus 消息提示
- 前端不直接连接 MySQL
- 前端不直接执行 Pytest
- 前端不直接请求被测接口，所有操作都通过后端 API 完成

## 当前限制

- 当前仍为 mock AI，不接真实 AI。
- 不实现复杂低代码用例编排。
- 不实现复杂流程图依赖编排。
- 不实现权限系统和登录系统。
- 不实现多租户。
- 不实现 CI/CD。
- 不实现 WebSocket 实时日志。
- 不引入复杂可视化库。
- 不实现复杂大屏。
- JSON 字段暂时使用 textarea 展示和编辑。
