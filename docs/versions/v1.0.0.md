## AI 输出标准

```json
{
  "test_strategy": {
    "normal": [],
    "error": [],
    "boundary": [],
    "security": []
  }
}
```

单条用例必须包含 `name`、`purpose`、`request`、`assertions`、`risk_level`、`reason`。`assertions` 必须是 DSL 字符串数组。

## 兼容性

- 不修改 execution_engine。
- 不修改数据库结构。
- 不改变 `POST /api/v1/endpoints/{endpoint_id}/testcases/generate` 路径。
- 生成结果继续保存到 `test_case`。
- AI 调用记录继续保存到 `ai_analysis_record`。
- 未配置 `AI_API_KEY` 时，用例生成接口返回明确配置错误。

## 第11阶段增强：AI 测试策略生成

状态：已完成。

### 本次变更

- Prompt 从“生成测试数据”升级为“生成接口测试策略”。
- AI 输出主结构调整为 `test_strategy`。
- 策略分类增加 `security` 安全测试用例。
- 单条用例新增 `purpose`、`reason`、`risk_level`，用于说明测试目的、设计原因和风险等级。
- 后端标准化器校验四类策略用例均非空。
- 后端标准化器校验 DSL 断言，不允许对象断言、空断言或 `business_code == 1`。
- 校验通过后继续保存到现有 `test_case` 表，不修改数据库结构。

### 权威输出结构

```json
{
  "test_strategy": {
    "normal": [
      {
        "name": "正常查询",
        "purpose": "验证正常用户可以查询成功",
        "request": {"headers": {}, "query": {}, "path": {}, "body": {}},
        "assertions": ["status_code == 200", "$.code == 200"],
        "risk_level": "P1",
        "reason": "覆盖主业务成功路径"
      }
    ],
    "error": [],
    "boundary": [],
    "security": []
  }
}
```

## 第11阶段增强：Test Coverage Engine 1.0

状态：已完成。

### 本次变更

- 新增 `backend/app/services/coverage_engine.py`。
- AI 用例生成从单纯接口 Schema 输入升级为 `API Schema + Coverage Matrix`。
- 固定生成 7 类覆盖维度：`functional`、`validation`、`boundary`、`negative`、`security`、`business`、`dependency`。
- Prompt 要求模型按覆盖维度生成测试策略。
- 标准化器校验每条用例的 `coverage_dimension`。
- 标准化器校验所有覆盖维度都存在且满足最小数量。
- `POST /api/v1/endpoints/{endpoint_id}/testcases/generate` 返回 `coverage_matrix` 和 `coverage_summary`。

### Coverage Matrix

```json
{
  "coverage_matrix": {
    "functional": true,
    "validation": true,
    "boundary": true,
    "negative": true,
    "security": true,
    "business": true,
    "dependency": true
  }
}
```

### 兼容性

- 不修改 execution_engine。
- 不修改 DSL 语法。
- 不修改数据库结构。
- 不修改 `testcases/generate` 接口入参。
- 接口响应新增覆盖率字段，不影响原有 `test_cases` 返回。
## 第11阶段修复：AI 用例生成稳定性与覆盖率展示

状态：已完成。

### 修复内容

- 修复真实大模型生成耗时超过前端全局 20 秒超时后，浏览器 Network 中 `generate` 请求显示 `canceled` 的问题。
- 前端 AI 用例生成请求单独设置为 120 秒超时。
- 修复模型返回无法解析的 DSL 字符串时，后端标准化阶段抛出异常并导致接口 500 的问题。
- 后端现在会丢弃非法 DSL 字符串，并按 `coverage_dimension` 补入默认断言。
- `coverage_matrix` 和 `coverage_summary` 继续随生成接口返回，供前端展示测试覆盖率卡片。

### 兼容性

- 不修改 `execution_engine`。
- 不修改 DSL 语法。
- 不修改数据库结构。
- 不修改 `testcases/generate` 接口入参。
- 原有 `test_cases` 返回结构保持兼容。
