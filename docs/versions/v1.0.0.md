# v1.0.0 版本记录

## 第11阶段：AI 用例生成 + 测试用例自动生成优化

状态：已完成。

## 本次变更

- 新增真实 AI 用例生成能力。
- 支持通过 OpenAI-compatible Chat Completions 接口调用真实大模型。
- 新增 Swagger/OpenAPI 接口资产到结构化 AI 输入模型的转换。
- 新增 Prompt 工程，要求 AI 只返回结构化 JSON。
- 新增 AI 输出标准化模块，将模型输出转换为平台可执行测试用例结构。
- 新增 DSL 自动生成能力，将 AI 输出中的断言标准化为 DSL。
- OpenAI 配置统一使用 `AI_API_BASE_URL=https://api.openai.com/v1`，客户端自动请求 `/chat/completions`。

## AI 输出标准

```json
{
  "test_cases": [
    {
      "type": "normal|error|boundary",
      "request": {},
      "assertions": [
        {
          "type": "status_code",
          "expected": 200
        },
        {
          "type": "dsl",
          "expression": "$.code == 200"
        }
      ]
    }
  ]
}
```

## 兼容性

- 不修改 execution_engine。
- 不修改数据库结构。
- 不改变 `POST /api/v1/endpoints/{endpoint_id}/testcases/generate` 路径。
- 生成结果继续保存到 `test_case`。
- AI 调用记录继续保存到 `ai_analysis_record`。
- 未配置 `AI_API_KEY` 时，用例生成接口返回明确配置错误。
## 第11阶段专项修复：mock LLM 替换为真实 OpenAI 调用

状态：已完成。

### 本次修复

- 新增真实 OpenAI Python SDK 客户端：`backend/app/ai/clients/openai_client.py`。
- `backend/app/ai/llm_client.py` 仅保留兼容导出，不再实现手写 `httpx` LLM 调用。
- AI 用例生成接口运行时必须调用真实 OpenAI；`AI_API_KEY` 缺失时返回明确配置错误。
- 禁止运行时静默 fallback 到 mock/fake LLM。
- mock/fake LLM 仅用于单元测试。
- AI 输出断言统一为 DSL 字符串数组。
- 模型返回非 JSON 或结构不合法时不保存半成品测试用例。

### 输出结构

```json
{
  "test_cases": [
    {
      "name": "正常查询",
      "type": "normal",
      "request": {
        "headers": {},
        "query": {},
        "path": {},
        "body": {}
      },
      "assertions": [
        "status_code == 200",
        "$.code == 200"
      ]
    }
  ]
}
```

### 兼容性

- 不修改 `POST /api/v1/endpoints/{endpoint_id}/testcases/generate` 入参结构。
- 不修改 execution_engine。
- 不修改 DSL 语法。
- 不新增数据库表。
- 不影响历史 mock 生成的测试用例。

## 第11阶段增强：OpenAI / Qwen 多模型适配

状态：已完成。

### 本次变更

- 新增 `backend/app/ai/llm_factory.py`。
- 新增 `backend/app/ai/clients/qwen_client.py`。
- AI 用例生成支持通过 `AI_PROVIDER=openai|qwen` 切换模型供应商。
- OpenAI 分支继续使用 `response_format={"type": "json_object"}`。
- Qwen / DashScope compatible mode 分支不传 `response_format`，由后端执行 JSON 强校验。
- 业务层不直接判断模型供应商，不直接调用 SDK。
- 不允许 mock fallback 或静默降级。

### 配置示例

```text
AI_PROVIDER=openai
AI_API_BASE_URL=https://api.openai.com/v1
AI_MODEL_NAME=gpt-4o-mini
```

```text
AI_PROVIDER=qwen
AI_API_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_MODEL_NAME=qwen-max-latest
```

### 兼容性

- 不修改 execution_engine。
- 不修改 DSL 语法。
- 不修改数据库结构。
- 不修改 `testcases/generate` 接口入参。
